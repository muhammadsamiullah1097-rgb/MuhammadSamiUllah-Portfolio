Decision-support tool

Pakistan Flood Prediction System.

Problem

Flood-risk information in Pakistan is scattered — forecasts, river discharge, soil moisture and official advisories live in separate places, and raw numbers don't tell a district officer what to do next.

Pipeline

Live ingestion from Open-Meteo (forecast + archive), Open-Meteo Flood/GloFAS discharge, NASA POWER soil moisture, GDACS events and ReliefWeb — plus a PMD advisory client (weather.gov.pk) with an NLP analyzer. 78 cities/districts in a Pakistan gazetteer.

Intelligence

River-specific ML model where suitable history exists, inspectable rule-based fallback otherwise. Every assessment ships an explainable reasoning trace — likely causes, warning window, damage-risk context — in JSON and Markdown.

Live system

Deployed on GitHub Pages: national risk reports plus an interactive dashboard with a Scenario Lab (rainfall/soil/river/seasonality sliders, instant recalculation, JSON export) and a live Open-Meteo rain feed.
